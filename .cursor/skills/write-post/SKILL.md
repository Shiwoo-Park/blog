# 포스팅 작성

언급한 주제 또는 요청 내용에 대하여 블로그 포스팅 작성을 완성시킨다.
**"글 작성" 지시 전에는 본문을 쓰지 않는다** — 구성안 검토가 먼저다.

## 작성 단계

1. **주제 명확화**: 제시한 주제에 대해 구체화가 필요하거나 질문이 있으면 먼저 질문한다.
2. **구성안 제시**: 글의 단락별 주제를 요약해, 어떤 식으로 내용이 구성될지 한눈에 확인·검토할 수 있게 표시한다.
3. **피드백 → 반영 반복**: 구성안에 대한 피드백을 받아 수정하고, 다시 2번으로 돌아간다. 사용자가 "글 작성"이라고 말할 때까지 반복한다.
4. **글 작성**: 사용자가 "글 작성"이라고 했을 때만 이 단계에 들어간다. 확정된 구성에 따라 본문을 생성한다.

## 작성 원칙

- `posts/_post_template.md` 양식(프론트매터 포함)을 그대로 따른다.
- 날짜는 반드시 **오늘 날짜**를 기입한다.
- 프론트매터의 `categories`, `description`(150~160자), `keywords`, `image`를 채운다.
  - 개발: `/resources/og-dev.png`
  - 투자: `/resources/og-invest.png`
  - 여행: `/resources/og-travel.png`
  - 기본: `/resources/og-default.png`
- 작성 후, 카테고리에 맞는 목록 파일의 **해당 년월 섹션 최상단**에 링크를 추가한다.
  - 개발 블로그: `posts/dev/home.md`
  - 투자 블로그: `posts/invest/home.md`
  - 여행 블로그: `posts/travel/home.md`
  - 코드 스니펫: `snippets/home.md`
  - (예) `posts/dev/*/my_post.md` → `posts/dev/home.md`에 추가
  - 해당 년월 섹션이 없으면 새로 만들어 추가한다.

## 작성 방식

1. 되도록 장황하지 않게 핵심만 간결하게 쓴다.
2. 특정 지식을 설명할 때는 해당 주제를 잘 모르는 사람도 이해할 수 있게 쓴다.
3. 내용이 복잡하거나 이해하기 어려우면 간단한 예시를 곁들인다.
4. 깊이 있는 개념은 가장 기본이 되는 지식부터 점진적으로, 핵심만 간단히 덧붙여 이해를 돕는다.
5. 작성 전에 웹 검색으로 최신 정보를 확인해 내용의 진위·최신성을 검증한다.
6. 맨 마지막에 전체 핵심만 아주 간단히 정리한 **핵심요약** 섹션을 별도로 둔다.

## 산출물 체크리스트

- [ ] 템플릿 프론트매터 전 항목 작성 (title / date / categories / description / keywords / image)
- [ ] 날짜 = 오늘
- [ ] 본문 섹션 번호 체계(`## 1.`, `### 1-1.`) 유지
- [ ] **핵심요약** 섹션 존재
- [ ] 카테고리 `home.md` 해당 년월 최상단에 링크 추가
