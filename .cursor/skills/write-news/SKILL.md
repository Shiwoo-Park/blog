# 뉴스 작성

언급한 주제 또는 요청 내용에 대하여 뉴스 글을 작성한다.
일반 포스팅과의 차이는 **리서치 비중**이다 — 최신성과 정확성이 최우선이다.
**"글 작성" 지시 전에는 본문을 쓰지 않는다.**

## 작성 단계

1. **주제 명확화**: 제시한 제목에 대해 내용 구체화가 필요하거나 질문이 있으면 먼저 질문한다.
2. **리서치**: 충분한 웹 검색으로 최신 정보를 조사하고 데이터를 수집한다. 최신성과 정확성에 중점을 두고, 필요하면 해외 사이트까지 확인한다. 수집한 수치·인용은 출처를 남긴다.
3. **구성안 제시**: 글의 단락별 주제를 요약해, 어떤 식으로 내용이 구성될지 한눈에 확인·검토할 수 있게 표시한다.
4. **피드백 → 반영 반복**: 구성안에 대한 피드백을 받아 수정한 뒤 다시 3번으로 돌아간다. 사용자가 "글 작성"이라고 말할 때까지 반복한다.
5. **글 작성**: 사용자가 "글 작성"이라고 했을 때만 이 단계에 들어간다. 확정된 구성에 따라 본문을 생성한다.

## 작성 원칙

- `posts/_post_template.md` 양식(프론트매터 포함)을 그대로 따른다.
- 날짜는 반드시 **오늘 날짜**를 기입한다.
- 작성 후, 카테고리에 맞는 목록 파일의 **해당 년월 섹션 최상단**에 링크를 추가한다.
  - 개발 블로그: `posts/dev/home.md`
  - 투자 블로그: `posts/invest/home.md`
  - 여행 블로그: `posts/travel/home.md`
  - (예) `posts/dev/*/my_post.md` → `posts/dev/home.md`에 추가
- 시점에 민감한 내용은 본문에 **기준 날짜**를 명시한다.

## 작성 방식

1. 뉴스 내용 이해에 배경지식이나 상황 설명이 필요하면 그 부분도 간략히 설명한다.
2. 초보자나 일반인도 쉽게 이해할 수 있도록 쓴다.
3. 데이터 시각화를 위해 도표·차트·이미지를 적극 활용한다 (필요하면 외부 링크를 가져온다).
4. 독자가 실질적으로 가장 궁금해하거나 필요로 하는 정보만 남기도록 구성한다.
5. 맨 마지막에 전체 핵심만 아주 간단히 정리한 **핵심요약** 섹션을 별도로 둔다.

## 산출물 체크리스트

- [ ] 주요 수치·주장에 출처(링크) 명시
- [ ] 템플릿 프론트매터 전 항목 작성
- [ ] 날짜 = 오늘 / 기준 시점 명시
- [ ] 도표·차트 등 시각 자료 1개 이상
- [ ] **핵심요약** 섹션 존재
- [ ] 카테고리 `home.md` 해당 년월 최상단에 링크 추가
